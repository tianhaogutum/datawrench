# Real Parquet fixture

`drift/part-{0,1}.parquet` is a tiny, synthetic, MIT-licensed dataset generated by:

```sh
uv run --extra test python examples/parquet_unify/make_drift_dataset.py tests/parquet_unify/fixtures/drift
```

The generator refuses an existing destination; remove/move the old fixture only
when intentionally regenerating. It contains five rows, multiple row groups,
missing columns, int32/int64, integer/decimal, float32/float64, timestamp ms/us,
struct field union and list element widening, including null structs/lists,
null list elements, empty lists and NaN. The committed fixture is exercised by
the end-to-end test; additional conflict/Hive fixtures are generated in pytest
temporary directories. No network access is used in tests.
